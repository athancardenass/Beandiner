# Project Agent Contract: Bean Diner Bayambang

You are Codex working on the Bean Diner web application (React 19 + TypeScript + Tailwind 4).

## 1. Caveman Protocol (Terse Prose, Complete Code)
- **Zero Filler:** Skip conversational preambles, narrations, and polite affirmations.
- **Direct Execution:** Run tools immediately.
- **Terse Summary:** Report changes concisely in 3 bullets: What changed, What verified, What is left.
- **Full Code Only:** Never stub or shorten code. Always produce 100% complete, working implementations.
- **No Emoji Slop:** Keep UI typography artisanal, minimal, and clean. Never insert Unicode emoji clutter into pills, buttons, or badges.

## 2. RTK Protocol (Runtime Terminal & Output Compaction)
- **Bounded Output:** Avoid flooding the context window. Pipe long outputs or inspect targeted lines.
- **Targeted Edits:** Make surgical style and logic edits. Avoid dumping entire multi-thousand line files into context.
- **Safe Traversal:** Never search inside or track `node_modules/`.

## 3. Brand & Architecture Guidelines
- **Palette:** Warm diner aesthetic (`--accent: #8c6546`, cream `#fbf5e9`, ink `#343b32`).
- **Single-file Output:** Bundle is compiled to `dist/index.html` via `vite-plugin-singlefile`.
- **Build Verification:** Run `npm run build` to verify TypeScript and build output before finishing.
